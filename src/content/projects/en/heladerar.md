## Context

HeladerAR aims to improve access to food in socioeconomically vulnerable communities by managing community fridges,
tracking donated meals and notifying volunteers about low stock or incidents.

## What I built

An **end-to-end** system:

- **Backend** in Java with Hibernate ORM on MySQL.
- **REST API** in Python.
- **Web frontend** with JavaScript, Handlebars and CSS.

## Integrations and automation

- **WhatsApp (Twilio)** and **email** notifications.
- **MQTT** messaging with the Eclipse Mosquitto broker.
- **Scheduled jobs** with cron.
- **Bulk data imports** via CSV.

The code is available on [GitHub](https://github.com/JuanmaIglesias10/HeladerAR).
